# WorkExe（桌面互动人物）

> 一个可常驻桌面的 WPF 互动人物程序，可替换为老板照片，支持多种"惩罚"玩法。

## 项目简介
WorkExe 是一个基于 WPF（.NET Framework 4.8）的桌面宠物 / 互动人物程序。它常驻在屏幕底部中央，是一个透明无边框的悬浮窗，可左键拖拽、右键唤出菜单。用户可上传一张照片（如老板），程序自动将其合成进站立、磕头、爬行、受击、炮击、被牛撞飞等动作，实现"桌面互动"效果。

## 功能特性
- 透明无边框悬浮窗，默认屏幕底部中央待命
- 左键拖拽移动，限制在工作区内
- 右键现代浅色圆角菜单：鞭子抽打 / 大炮惩罚 / 召唤牛 / 说"我错了" / 磕头 / 爬行 / 调整大小 / 始终置顶 / 隐藏 / 恢复默认 / 退出
- 小 / 中 / 大三档尺寸
- 系统托盘图标：显示 / 隐藏 / 恢复 / 退出
- 鞭子模式：全屏透明层，鞭子随鼠标移动，点击人物触发受击
- 大炮模式：空格蓄力（多段台词循环），松开发射飞出屏幕
- 牛模式：牛从人物对侧出现并撞飞人物
- 全局快捷键 `Esc` / 右键退出玩法；`Ctrl + Alt + Shift + Q` 紧急恢复
- 粉色气泡台词，靠近边缘向内展开
- 完整设置界面：照片、大小、不透明度、置顶、任务栏、开机自启、台词编辑

## 技术栈
- WPF / .NET Framework 4.8（C#）
- XAML + DispatcherTimer 动画
- Win32 API（置顶看门狗、全局键盘钩子、工作区约束）
- 原生 GDI+ 素材生成器（无需 Python）

## 本地运行
1. 安装 Visual Studio 2022（含 .NET Framework 4.8 与 WPF 工作负载）或 MSBuild。
2. 打开 `WorkExe.sln`，以 Release 编译。
3. 运行生成的 `WorkExe.exe`，或双击 `Run.bat`。
